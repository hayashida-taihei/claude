# スペースインベーダーゲーム

HTML5 CanvasとJavaScriptで作成されたクラシックなスペースインベーダーゲームです。

## 特徴

- クラシックなスペースインベーダーのゲームプレイ
- 4種類の異なるタイプのインベーダー
- スコアシステム
- レベルアップシステム（全ての敵を倒すと次のレベルへ）
- 敵の反撃（敵も弾を発射します）

## 遊び方

1. `index.html` をブラウザで開く
2. 操作方法:
   - **矢印キー（左/右）**: プレイヤーを移動
   - **スペースキー**: 弾を発射
   - **Rキー**: ゲームをリスタート

## ゲームルール

- 全てのインベーダーを倒すとレベルアップします
- インベーダーが画面下部に到達するとゲームオーバーです
- 敵の弾に当たるとゲームオーバーです
- 敵のタイプによってスコアが異なります

## 技術仕様

- HTML5 Canvas
- Pure JavaScript（フレームワーク不要）
- レスポンシブデザイン

## ブラウザの互換性

モダンなWebブラウザ（Chrome, Firefox, Safari, Edge）で動作します。
